# Trivia Quiz Application
This project implements a trivia quiz application in Python, using a SQLite database to store and retrieve questions, answers, and categories. The program allows users to test their knowledge and provides feedback on their performance.

## Features
- Connects to a SQLite database containing trivia questions and answers.
- Categorizes questions by topic.
- Randomly selects questions for the quiz.
- Tracks and displays the user's score.
- Provides immediate feedback on each answer (correct or incorrect).

## Problem Addressed
Creating and managing trivia quizzes manually can be inefficient and repetitive. This application automates quiz creation, randomizes questions, and ensures an engaging user experience.

## How to Use
1. **Run the Program**: Execute the Python script to start the trivia quiz:
   ```bash
   python trivia.py
   ```
2. **Answer Questions**: The program will display a series of trivia questions. Input your answer for each question.
3. **View Results**: After completing the quiz, the program will display your score and performance.
