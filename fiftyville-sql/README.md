# Fiftyville Investigation
This project implements a SQL-based investigation into a fictional town, Fiftyville. The goal is to solve a mystery using SQL queries to analyze a SQLite database containing records of residents, transactions, and activities in the town.

## Features
- Connects to a SQLite database with structured data about Fiftyville.
- Allows users to perform SQL queries to gather evidence and solve the mystery.
- Includes information such as:
  - Transactions at businesses.
  - Residents' personal data and movements.
  - Town events and activities.
- Encourages logical deduction through data analysis.

## Problem Addressed
Solving a complex mystery in a large dataset manually is impractical. This project uses SQL to extract insights, filter information, and uncover hidden patterns to solve the case efficiently.

## How to Use
1. **Load the Database**: Use a SQLite-compatible tool or the command line to access the Fiftyville database.
2. **Query the Data**: Execute SQL queries to investigate clues, such as:
   - Identifying suspicious transactions.
   - Analyzing movements of residents.
   - Finding connections between events.
3. **Solve the Mystery**: Use the insights gathered from queries to deduce the solution to the case.
