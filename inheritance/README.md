# Inheritance
This project simulates the inheritance of blood types in C. It demonstrates how genetic traits are passed down from parents to children using linked structures to represent family trees.

## Features
- Simulates the inheritance of blood types across multiple generations.
- Creates a family tree of individuals with random or predefined genetic traits.
- Uses linked structures to represent relationships between parents and children.
- Outputs the family tree, displaying each individual's blood type and parentage.

## Problem Addressed
This simulation helps illustrate the principles of inheritance and genetic probability, making it easier to understand how traits are passed down through generations.

## How to Use
1. **Compile the Program**: Use a C compiler to compile the source code, e.g., `clang inheritance.c -o inheritance`.
2. **Run the Program**: Execute the compiled program to generate a family tree:
   ```bash
   ./inheritance
   ```
3. **View Results**: The program will output the family tree, showing blood types and parentage for each individual.
