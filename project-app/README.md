# PROJECT TITLE - QUIZZZ HUB

#### Video Demo:  <https://www.youtube.com/watch?v=IMChytXYpa0>

#### Description:

QUIZZZ HUB is a web application that allows users to create and share interactive quizzes easily.
As a quiz creator, you can register for an account and start designing your own quizzes. Once a
quiz is created, you can generate a shareable link and pass it to anyone you’d like. Quiz takers
with the link do not need to log in to take the quiz, ensuring a seamless experience.

Key Features :
Create Quizzes: Simple and intuitive interface to create your own quizzes.
Shareable Links: Generate a link to share your quiz with friends or colleagues.
Guest Access: Quiz takers do not need to register or log in to participate.

1. create_quiz.html
This page allows users to create a new quiz by entering a quiz name, a description, and adding
multiple-choice questions with answer options. Users can dynamically add or remove questions
and their choices before submitting the quiz.

2. index.html
This is the home page where users can see a list of all the quizzes they have created. It shows the
quiz titles and provides options to copy the quiz link or delete it. If no quizzes
have been created yet, a message informs the user.

3. layout.html
This is the base template for all pages. It contains a navigation bar, a footer, and a section
where content from other pages can be displayed. It helps maintain a consistent look and feel
throughout the website.

4. login.html
This page allows users to log in by providing their username and password. It includes a form where
users can enter their credentials and submit them to access their account.

5. quiz.html
This page displays a specific quiz for users to take. It shows the quiz name, description, and the
set of questions with multiple-choice answers for users to select from before submitting their responses.

6. register.html
This page allows new users to register for an account by providing a username, password, and confirming
their password. Once the form is submitted, the user account is created.

7. result.html
This page shows the results of a quiz after it has been completed. It displays the user's score and a
message thanking them for participating in the quiz.

8. about.html
This page provides information about the QuizzzHUB platform. It includes the platform's logo and a
brief description of its purpose and features.

9. apology.html
This is an error page that displays a message explaining why an error occurred, along with an
error code. It also includes a button to return to the home page.

10. contact.html
This page allows users to get in touch with me. It includes a contact form for
submitting inquiries and displays the platform’s contact details such as email, phone number, and address.


Future Enhancements :
1. Quiz Editing: Ability to edit and add questions to quizzes after creation.
2. Unique URLs: Generate unique URLs for each quiz for better management.
3. Enhanced Design: Improve the visual aesthetics of the entire app.
4. Custom Options: Add more flexible question types beyond fixed questionnaires.
5. Quiz Taker Data: Save quiz taker responses in a database for creators to review results.

Notes :
The application is fully functional in its current state. The future enhancements listed above
are planned improvements to enhance the user experience. Due to time constraints at the end of
the year, these features were not implemented in the current version.

Thank you for exploring QUIZZZ HUB!
