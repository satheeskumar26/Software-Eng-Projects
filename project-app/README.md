# QUIZZZ HUB

#### Video Demo:  <https://www.youtube.com/watch?v=IMChytXYpa0>

#### Description:
QUIZZZ HUB is a web application that allows users to create and share interactive quizzes easily. As a quiz creator, you can register for an account and start designing your own quizzes. Once a quiz is created, you can generate a shareable link and pass it to anyone you’d like. Quiz takers with the link do not need to log in to take the quiz, ensuring a seamless experience.

## Key Features
- **Create Quizzes**: Simple and intuitive interface to create your own quizzes.
- **Shareable Links**: Generate a link to share your quiz with friends or colleagues.
- **Guest Access**: Quiz takers do not need to register or log in to participate.

### Pages Overview
1. **create_quiz.html**:
   - Allows users to create a new quiz by entering a quiz name, a description, and adding multiple-choice questions with answer options.
   - Users can dynamically add or remove questions and their choices before submitting the quiz.

2. **index.html**:
   - Home page showing a list of all quizzes created by the user.
   - Provides options to copy the quiz link or delete it.
   - Displays a message if no quizzes have been created yet.

3. **layout.html**:
   - Base template for all pages, containing a navigation bar, footer, and a section for content from other pages.
   - Ensures a consistent look and feel throughout the website.

4. **login.html**:
   - Allows users to log in with a username and password.
   - Includes a form for entering credentials to access their account.

5. **quiz.html**:
   - Displays a specific quiz for users to take, including the quiz name, description, and questions with multiple-choice answers.

6. **register.html**:
   - Enables new users to register for an account by providing a username and password.
   - Ensures user accounts are securely created.

7. **result.html**:
   - Displays the results of a completed quiz, including the user’s score and a thank-you message.

8. **about.html**:
   - Provides information about the QUIZZZ HUB platform, including the platform’s logo and a brief description of its purpose and features.

9. **apology.html**:
   - Error page that displays a message explaining the cause of an error and includes a button to return to the home page.

10. **contact.html**:
    - Allows users to get in touch via a contact form for inquiries.
    - Displays the platform’s contact details, including email, phone number, and address.

## Future Enhancements
1. **Quiz Editing**: Ability to edit and add questions to quizzes after creation.
2. **Unique URLs**: Generate unique URLs for each quiz for better management.
3. **Enhanced Design**: Improve the visual aesthetics of the entire app.
4. **Custom Options**: Add more flexible question types beyond fixed questionnaires.
5. **Quiz Taker Data**: Save quiz taker responses in a database for creators to review results.
