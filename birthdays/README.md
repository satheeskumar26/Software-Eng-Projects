# Birthdays Database Management
This project implements a simple Python application to manage a birthdays database using SQLite. The program allows users to add, query, and delete birthday entries efficiently.

## Features
- **Add Birthdays**: Insert new entries into the database with names and dates.
- **View Birthdays**: List all stored birthdays in a user-friendly format.
- **Query Specific Birthdays**: Search for birthdays by name.
- **Delete Entries**: Remove specific birthday records from the database.
- **Integration with SQLite**: Ensures data persistence and efficient querying.

## Problem Addressed
Manually managing and organizing birthday information can be tedious and error-prone. This application automates the process, ensuring data is stored securely and is easily accessible.

## How to Use
1. **Run the Program**: Execute the Python script to interact with the database:
   ```bash
   python birthdays.py
   ```
2. **Add a Birthday**: Follow the prompts to input a name and date.
3. **Query Birthdays**: Search for birthdays by name or list all stored entries.
4. **Delete an Entry**: Remove specific records by name or ID.
