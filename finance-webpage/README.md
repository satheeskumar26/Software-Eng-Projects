# Finance Application
This project implements a web-based finance application using Python and Flask, allowing users to manage their stock portfolios. It integrates with real-time stock data to facilitate buying, selling, and monitoring stocks while keeping track of user balances.

## Features
- **User Authentication**: Secure user registration and login system.
- **Stock Quote**: Fetch real-time stock prices and display them to users.
- **Buy Stocks**: Purchase stocks and update the user’s portfolio and balance.
- **Sell Stocks**: Sell owned stocks and update the portfolio and balance accordingly.
- **Transaction History**: Record all buy and sell transactions for users to review.
- **Portfolio Overview**: Display the user’s current holdings with their market value and total balance.
- **Integration with APIs**: Fetch real-time stock data using a public API.

## Problem Addressed
Managing stock portfolios manually can be error-prone and inefficient. This application automates the process, providing users with a streamlined interface to track and manage their investments.

## How to Use
1. **Run the Application**: Start the Flask web server:
   ```bash
   flask run
   ```
2. **Register/Login**: Create a new account or log in with an existing one.
3. **Search Stocks**: Use the search bar to find stock prices in real-time.
4. **Buy/Sell Stocks**: Perform transactions to manage your portfolio.
5. **View Portfolio**: Monitor current holdings, their value, and transaction history.

This project was part of my Harvard CS50x coursework, designed to deepen my understanding of web development, APIs, and database management while providing practical experience in building financial applications.
